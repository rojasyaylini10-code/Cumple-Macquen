# 🎂🏎️ Cumpleaños de Bryan Martinez

Página web de cumpleaños con temática de carreras inspirada en Rayo McQueen.

## Archivos
- `index.html` — estructura de la página.
- `style.css` — diseño, animaciones y responsive.
- `script.js` — confeti y ventana sorpresa.

## Cómo subirla a GitHub
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css` y `script.js`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub Pages publique la página.

## Nota
El diseño usa una estética de carreras y un auto rojo inspirado en el personaje, en lugar de copiar imágenes oficiales del personaje. Así puedes publicar el proyecto sin tener que incluir imágenes oficiales de Disney/Pixar.
